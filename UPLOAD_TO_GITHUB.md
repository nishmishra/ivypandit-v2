# Uploading this IvyPandit update to GitHub

This package is prepared for the existing `nishmishra/ivypandit-v2` repository.

1. Unzip this archive on your computer.
2. Open the extracted folder.
3. Select **the contents inside the folder** (`app`, `components`, `content`, `data`, `public`, and the root files).
4. On GitHub, use **Add file → Upload files** at the repository root.
5. Drag the selected contents into GitHub. The displayed paths should begin with `/app/...`, `/public/...`, or a root filename — there should be no extra enclosing folder name.
6. Commit to `main` only after the paths look correct.
7. Vercel should deploy automatically. Confirm the new production deployment is **Ready** before considering the update complete.
