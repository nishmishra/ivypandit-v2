# IvyPandit structured data

This directory is reserved for the portable knowledge layer behind IvyPandit.

Planned collections:
- `literature/` — indexed scholarly literature and bibliographies
- `research-questions/` — structured research-question repository
- `iks/` — institutions, journals, archives, courses, opportunities, people
- `sbkb/` — Sanskrit Biomedical Knowledge Base records

Prefer open formats such as CSV, JSON, Markdown, and UTF-8 plain text. Avoid making a proprietary cloud database the only copy of an intellectual asset.
